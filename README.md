# LEARNING

Course material, labs and notes. One directory per course.

## Layout

```text
LEARNING/
└── <course-name>/
    ├── README.md     what the course covers, where I got to
    ├── notes/
    └── labs/
```

## Conventions

- Directory names lowercase with hyphens — `certified-kubernetes-administrator`,
  not `CKA Course (KPLABS)`.
- Each course gets its own `README.md` saying what it is, who publishes it, and
  how far through it I am. That is the thing worth having later.
- Notes in Markdown, not PDFs or screenshots, so they stay greppable.
- Lab files that only make sense next to their notes live in the same directory.
